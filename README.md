project name : HelpingHands BD

short description : A community-driven platform where neighbours create, join and track social service events in their local area, such as winter clothes distributions, blanket drives, cleanups and plantations.

Features
1. Browse upcoming community service events. Past events never appear, and you can search by title or filter by event type.

2. Create, update and delete your own events, with form validation and a rule that the event date must be in the future.

3. Join an event with one click. Each event shows how many volunteers have joined.

4. Joined Events page lists every event you signed up for, sorted by event date.
6. Secure email/password login and GitHub login with BetterAuth. Protected API routes are verified with JWT.
7. Private pages (Create Event, Manage Events, Joined Events, Profile) stay open after a page reload for logged-in users.
8. Light and dark theme toggle that restyles the whole site.
9. Fully responsive layout for mobile, tablet and desktop.
10. Loading skeletons while data loads, and a profile page to update your name and photo.
